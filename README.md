# stock

A股日内做T量化回测系统，支持网格策略、ML择日和参数自适应。

## 功能

- **网格做T回测**：基于5分钟K线，模拟日内网格交易策略
- **ML择日**：用早盘30分钟特征（含跨日+日K线衍生特征）训练 XGBoost 分类器，预测当天是否适合做T
- **盘中自适应**：网格中心跟随日内VWAP动态移动
- **动态仓位**：根据早盘振幅自动调整每档买卖手数
- **策略对比**：批量对比买入持有 / 无ML做T / ML择日做T 三种策略

## ML择日模型说明

### 问题定义

预测某只股票某天**网格做T是否能盈利**，而非预测涨跌。振幅大、来回震荡的日子适合做T，单边趋势日不适合。

### 标签生成

对每只股票每天运行无ML的网格策略回测，计算T净贡献（做T额外收益）：
- T净贡献 > 0 → 标签 1（适合做T）
- T净贡献 ≤ 0 → 标签 0（不适合）

### 特征设计（28维）

| 特征组 | 维数 | 说明 |
|--------|------|------|
| 早盘特征 | 10 | 当天前6根5分钟K线（09:35~10:00）的振幅、斜率、VWAP偏离、量比等 |
| 跨日特征 | 8 | 昨日振幅/涨跌/量比、今日跳空、近5日振幅均值/标准差、成交量趋势 |
| 日K线特征 | 10 | 近5/20日均振幅、成交量z-score、趋势斜率、连续同向天数、换手率、距20日高点距离、PE分位、PB分位、preclose跳空幅度 |

**注**：所有特征均为开盘后30分钟内已知信息，无未来数据泄露。

### 训练配置

| 项目 | 配置 |
|------|------|
| 模型 | XGBoost（n_estimators=300, max_depth=4, lr=0.05） |
| 数据 | 沪深300全量300只，2024-01-15~2026-06-01（约2.5年） |
| 样本 | 170,506个交易日样本，正样本约50.7%（标签修正后均衡） |
| 切分 | 时序切分前80%训练、后20%测试（不随机打乱） |
| 并行 | 18进程并行回测+特征提取，约5分钟完成 |
| 不平衡处理 | scale_pos_weight 自动平衡正负样本 |
| pe/pb分位 | 滚动近2年窗口（500交易日），避免历史长度漂移 |
| 标签定义 | `daily_pnl - (close-open)×base_shares > 0`，即当天T操作净贡献为正 |
| 策略一致性 | 标签生成与推理均使用相同参数（间距1.5%，止损-1000元，关闭趋势过滤） |

### 模型效果（测试集 34,437天）

| 指标 | 值 |
|------|----|
| AUC | 0.795 |
| 准确率 | 72% |
| 做T精确率 | 71% |

### 关键结论

- **T净贡献长期正向**：2.5年30个月，无ML做T净贡献 +327.5万，网格T策略对底仓持有有正向贡献。
- **做T vs 纯持有**：做T总收益 +5,133万 vs 盘中持有 +4,806万，做T增厚约327万（+6.8%）。
- **ML择日效果**：ML_T净贡献 +280.3万，比无ML少约47万（-14.4%）。模型在弱市月份能提升正收益占比（如2024-08: ML 59% vs 无ML 32%），但会错过部分高收益的好日子，导致总收益略低。
- **T净贡献含义说明**：此处T净贡献仅含盘中操作净收益（不含隔夜跳空），因此数值小于直觉预期，这是正确的计算方式。

> 网格参数：间距1.5%，上下3档，每档300股，底仓5000股，止损-1000元/天。
