# stock

A股日内做T量化回测系统，支持网格策略、ML择日和参数自适应。

## 功能

- **网格做T回测**：基于5分钟K线，模拟日内网格交易策略
- **ML择日**：用早盘30分钟特征（含跨日+日K线衍生特征）训练 XGBoost 分类器，预测当天是否适合做T
- **盘中自适应**：网格中心跟随日内VWAP动态移动
- **动态仓位**：根据早盘振幅自动调整每档买卖手数
- **策略对比**：批量对比买入持有 / 无ML做T / ML择日做T 三种策略

## ML择日模型说明

### 问题定义

预测某只股票某天**网格做T是否能盈利**，而非预测涨跌。振幅大、来回震荡的日子适合做T，单边趋势日不适合。

### 标签生成

对每只股票每天运行无ML的网格策略回测，计算T净贡献（做T额外收益）：
- T净贡献 > 50 元 → 标签 1（适合做T）
- T净贡献 < -50 元 → 标签 0（不适合）
- |T净贡献| ≤ 50 元 → 排除（噪音，约占 77% 交易日）

使用阈值而非 `> 0` 的原因是微赚微亏日与手续费成本接近，标签噪声大，排除后模型 AUC 从 0.56 提升至 0.66。

### 特征设计（28维）

| 特征组 | 维数 | 说明 |
|--------|------|------|
| 早盘特征 | 10 | 当天前6根5分钟K线（09:35~10:00）的振幅、斜率、VWAP偏离、量比等 |
| 跨日特征 | 8 | 昨日振幅/涨跌/量比、今日跳空、近5日振幅均值/标准差、成交量趋势 |
| 日K线特征 | 10 | 近5/20日均振幅、成交量z-score、趋势斜率、连续同向天数、换手率、距20日高点距离、PE分位、PB分位、preclose跳空幅度 |

**注**：所有特征均为开盘后30分钟内已知信息，无未来数据泄露。

### 训练配置

| 项目 | 配置 |
|------|------|
| 模型 | XGBoost（n_estimators=300, max_depth=4, lr=0.05） |
| 数据 | 沪深300全量300只，2024-01-15~2026-06-01（约2.5年） |
| 样本 | ~40,000 个交易日样本（排除 |t_pnl|≤50 的噪音后），正样本约 41% |
| 切分 | 5折 expanding-window 时间序列交叉验证（不随机打乱） |
| 并行 | 18进程并行回测+特征提取 |
| 不平衡处理 | scale_pos_weight 自动平衡正负样本 |
| pe/pb分位 | 滚动近2年窗口（500交易日），避免历史长度漂移 |
| 标签定义 | `daily_pnl - (close-open)×base_shares > 50`，即当天T净贡献超过 50 元 |
| 策略一致性 | 标签生成与推理均使用相同参数（间距1.5%，止损-1000元，关闭趋势过滤） |

### 模型效果（5折时间序列交叉验证，mean ± std）

| 指标 | 值 |
|------|----|
| AUC | 0.6575 ± 0.0141 |
| 准确率 | 0.61 ± 0.01 |
| 做T精确率 | 0.52 ± 0.03 |
| 做T召回率 | 0.57 ± 0.03 |
| F1 | 0.54 ± 0.02 |

> 注1：AUC 标准差仅 0.014，说明模型在不同时间段表现稳定。
> 注2：测试集的分类指标不等于真实回测收益，真实效果见下方月度对比。

### 特征重要性（top 5）

1. `m_return`（早盘涨跌幅）：0.141 — 最强信号，早盘涨跌方向对T收益影响最大
2. `m_slope`（早盘价格斜率）：0.083
3. `m_first_gap`（第一根K线跳空）：0.064
4. `m_vwap_dev`（早盘VWAP偏离）：0.058
5. `m_low_pos`（最低价位置）：0.036

### 关键结论

- **T交易整体拖累收益**：无ML做T净贡献合计 -198.9万，ML择日 -66.4万。说明在当前网格参数下，无差别做T长期是亏损的。总收益几乎全部来自 buy-hold 底仓（+4,806万）。
- **ML择日显著优于无差别做T**：ML_T净贡献比无ML少亏 132.5万（-66.4万 vs -198.9万），亏损减少 67%。30个月中 26 个月 ML 表现更好。
- **新模型（标签阈值50，时间序列CV，AUC=0.66）比旧模型（AUC=0.56）改善 38%**：T交易亏损从 -107.5万 降至 -66.4万。
- **T净贡献为正的月份极少**：无ML仅 6/30 个月 T净贡献为正；ML仅 12/30 个月为正。最好的月份是 2024-09（ML_T +30.6万），最差是 2024-10（ML_T -32.1万）。
- **ML择日提升了"正收益日占比"**：ML_T正占比在多数月份略高于无ML_T正占比，说明模型确实在筛选更适合做T的日子。

> 网格参数：间距1.5%，上下3档，每档300股，底仓5000股，止损-1000元/天。
